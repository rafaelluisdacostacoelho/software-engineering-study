# Repositório de Estudos em Engenharia de Software

**Descrição curta:** Coleção organizada de notas e referências sobre arquitetura, padrões de projeto, testes, escalabilidade, concorrência e boas práticas de engenharia de software.

**Objetivo:** Servir como material de estudo e referência prática para desenvolvedores que querem aprofundar conceitos fundamentais e avançados.

## Conteúdo principal

- **Arquiteturas:** hexagonal, onion, DDD
- **Padrões de projeto:** Adapter, Bridge, Factory, Strategy, Observer, Decorator, entre outros
- **Testes & Qualidade:** TDD, BDD, testes unitários
- **Concorrência e operações críticas:** problemas clássicos, controle de concorrência em BD, transações (ACID)
- **Escalabilidade & Cloud:** padrões cloud-native, caching, microservices, event-driven
- **Princípios e práticas:** SOLID, KISS, DRY, Design for Testability, Separation of Concerns

## Como usar

- Comece pelo sumário em [SUMMARY.md](SUMMARY.md) (ordem de leitura + navegação).
- Os tópicos ficam consolidados em `book/`, agrupados nas mesmas pastas da raiz.
- Use este repositório como referência para estudos, preparação para entrevistas e revisão de conceitos técnicos.

## Como contribuir

- Abra uma issue para sugerir novos temas ou melhorias.
- Envie um pull request com novas notas ou correções; siga o estilo e a organização existente.
